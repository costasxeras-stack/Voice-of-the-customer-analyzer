# Changelog

All notable changes to this project. Versions follow [docs/versioning.md](docs/versioning.md).

## [0.1.0] - 2026-11-20

First release.

### Added
- Analysis of 8,201 real clothing reviews: complaint sentences found by a model trained on the "would recommend" answer, grouped by meaning with a local AI model, and ranked by how much more often they appear in unhappy reviews.
- Keyword baseline written before the AI grouping, on the same reviews.
- Results page with headline numbers, a ranked fix list by department, the keyword comparison and random example sentences for every theme.
- Step-by-step scripts that reproduce every number.
- Case study, product brief and four decision records.
